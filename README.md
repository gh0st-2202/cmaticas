# cmaticas - Primos

## ¿Por qué esta rama?

Mi pasión por los números primos es algo que llevo dentro desde que era pequeño...

Es por ello que, tras crear el proyecto `cmaticas` he decidido crear una rama en específico dedicada a este conjunto de números tan interesantes, donde poder explorarlos, entenderlos, crear mis propias herramientas y sobre todo, aprender con ellos.
