# cmaticas

## ¿Por qué este proyecto?

Cuando terminé 2º de Bachillerato y entré en DAM, me di cuenta de que no era exactamente lo que buscaba.

Esperaba encontrar formación orientada a la creación de estructuras, a poder hacer lo que quisiera con un ordenador. Pero no fue así. Lo que encontré fue el uso de estructuras predefinidas, creadas por ingenieros y puestas en bandeja para que cualquiera, siguiendo las reglas, pueda hacer lo que se le proponga de manera más fácil y sencilla.

Como habrás deducido, yo no soy de ese tipo de personas. Me gusta entender hasta el último bit de un ordenador, escalar, crear mi propia estructura. Odio ceñirme a reglas y limitaciones impuestas por otros.

Por eso he creado este repositorio. No porque esté en desacuerdo con el trabajo de quienes saben más que yo, sino porque quiero entender el porqué de esas estructuras, cómo funcionan internamente, cuáles son sus limitaciones y, si puedo, intentar mejorarlas sin cargarme nada.

Este es mi espacio para aprender matemáticas y C desde los cimientos.
