# 5.5 Funciones parciales

## Mi interpretación personal

Hasta ahora, todas las funciones que hemos considerado eran **totales**: estaban definidas para todos los valores de sus argumentos. Pero las funciones recursivas generales (con minimización) tienen un problema: la minimización solo está definida si existe un `n` que cumpla la condición. Si no existe, la función no está definida para ese argumento. No podemos decidir algorítmicamente si existe o no, por lo que no podemos enumerar todas las funciones recursivas totales.

La solución es ampliar el concepto a **funciones parciales**: funciones que pueden no estar definidas para algunos valores. Esto permite definir la minimización sin exigir la condición de existencia. Si no hay `n` que cumpla la condición, la función simplemente no está definida para ese argumento.

**La idea clave:** Las funciones recursivas parciales son la clase más amplia de funciones calculables mediante algoritmos. Toda función que se pueda calcular con un algoritmo es recursiva parcial. Y, a diferencia de las funciones recursivas totales, las funciones recursivas parciales sí se pueden enumerar explícitamente sin problema.

---

## El problema con las funciones recursivas totales

### Enumeración de funciones recursivas primitivas

Como las funciones recursivas primitivas siempre terminan y están definidas para todos los argumentos, podemos **enumerarlas**. Dado un número `m`, podemos calcular la `m`-ésima función recursiva primitiva `fm`. Esto es posible porque la definición de función recursiva primitiva es constructiva y acotada.

- Tenemos una función universal `F(m, n) = fm(n)` que es recursiva.
- Entonces `g(n) = F(n, n) + 1` es recursiva (por composición y suma).
- Pero `g` **no puede ser recursiva primitiva**: si lo fuera, existiría `m` tal que `g = fm`, y entonces `g(m) = fm(m) = F(m, m) = g(m) - 1`, contradicción.

**Conclusión:** La función `g` es un ejemplo de función recursiva (total) que no es recursiva primitiva. Esto demuestra que las funciones recursivas primitivas son una clase propia (más pequeña) que las funciones recursivas totales.

---

### Intento de enumerar funciones recursivas totales

Si intentamos hacer lo mismo con las funciones recursivas totales, nos encontramos con un problema: **no podemos decidir si una definición por minimización es válida**.

- Una definición por minimización `f(a) = µn [g(a, n) = 0]` solo es válida si para todo `a` existe un `n` tal que `g(a, n) = 0`.
- Aunque `g` sea recursiva y sepamos calcularla, no sabemos decidir algorítmicamente si esa condición se cumple para todos los `a`.
- Por tanto, no podemos enumerar todas las funciones recursivas totales de forma efectiva.

**Conclusión:** No hay una función universal para las funciones recursivas totales. No existe un algoritmo que, dado `m` y `n`, calcule `f_m(n)` para todas las `f_m` recursivas totales. Esto no contradice la tesis de Church-Turing: simplemente, la función `g(n) = f(n, n) + 1` (si existiera) no sería calculable por un algoritmo, porque no podemos enumerar las `f_m`.

---

## Funciones parciales: la solución

Una **función parcial** es una función que no necesariamente está definida para todos sus argumentos. Si la función no está definida para un argumento, simplemente decimos que "no converge" o que "no está definida" (similar a una función en C que puede entrar en un bucle infinito para ciertas entradas).

### Definición (5.10)

- Una función parcial `f` puede estar definida solo para algunos argumentos.
- Si `f(a_1, ..., a_n)` está definida, denotamos su valor como `f(a_1, ..., a_n)`.
- Si no está definida, decimos que `f(a_1, ..., a_n)` no está definido (o es indefinido).

### Métodos de construcción de funciones parciales

**1. Composición parcial:** `f` está definida para `(a_1, ..., a_k)` si:
- Todas las `h_i(a_1, ..., a_k)` están definidas.
- `g(h_1(...), ..., h_r(...))` está definida.

**2. Recursión parcial:** `f(0, a_1, ..., a_k) = g(a_1, ..., a_k)` y `f(n+1, ...) = h(n, f(n, ...), ...)`. `f` está definida solo si todos los pasos intermedios están definidos.

**3. Minimización parcial:** `f(a_1, ..., a_n) = µ m [g(a_1, ..., a_n, m) = 0]`. `f` está definida si **existe** un `m` que cumple `g(...) = 0` y para todos los `k < m`, `g(a_1, ..., a_n, k)` está definido (aunque no sea 0). Si no existe tal `m`, `f` es indefinida.

**Observación:** La minimización parcial no requiere que exista siempre un `m`. Si no existe, la función simplemente no está definida para ese argumento.

---

## Funciones recursivas parciales

Una función parcial es **recursiva parcial** si se puede construir a partir de las funciones elementales (cero, sucesor, proyecciones) usando composición, recursión y minimización **parcial** un número finito de veces.

**Propiedades:**
- Toda función recursiva (total) es recursiva parcial.
- Las funciones recursivas parciales son exactamente las **calculables mediante un algoritmo**. Si un algoritmo para una función no termina para ciertos argumentos, la función es parcial.
- Ahora **sí podemos enumerar explícitamente** todas las funciones recursivas parciales, porque cada paso de construcción está bien definido (incluso si la minimización no encuentra solución, la función es simplemente indefinida). No hay una condición de existencia que debamos verificar previamente.

---

## ¿Por qué no hay contradicción con la tesis de Church-Turing?

Si pudiéramos enumerar todas las funciones recursivas parciales y construir una función universal `U(m, n) = f_m(n)`, entonces `U` sería recursiva parcial (o al menos calculable). Pero, ¿qué pasa con la función `g(n) = U(n, n) + 1`?

- Si `g` fuera recursiva parcial, existiría `m` tal que `g = f_m`.
- Entonces `g(m) = f_m(m) = U(m, m) = g(m) - 1`, contradicción si `g(m)` está definida.
- La salida es que **`g` no puede ser recursiva parcial**, pero eso no contradice la tesis de Church-Turing porque **`g` no es calculable mediante un algoritmo**. La razón es que, aunque podamos enumerar las funciones recursivas parciales, la función universal `U` no es recursiva parcial (o no es calculable). Es la misma paradoja de la diagonalización de Cantor: no puede existir una enumeración completa y una función universal que sea calculable para todas las funciones.

En resumen, las funciones recursivas parciales son **exactamente** las funciones calculables por un algoritmo, pero la enumeración de todas ellas no puede ser efectiva (no podemos calcular `U(m, n)` para todo `m, n` porque algunas `f_m` pueden no estar definidas para algunos `n`). Eso es justo lo que hace que la función diagonal no sea calculable.

---

## Conclusión (Lo que me llevo)

1. **Las funciones recursivas primitivas son enumerables** y existe una función universal para ellas. Pero la función diagonal `g(n) = f_n(n) + 1` es recursiva, pero no primitiva.
2. **Las funciones recursivas totales no se pueden enumerar** porque no podemos decidir si una minimización es válida (condición de existencia).
3. **Las funciones parciales** evitan este problema: la minimización parcial no requiere condición de existencia; si no hay solución, la función es indefinida.
4. **Las funciones recursivas parciales son exactamente las calculables por un algoritmo** (tesis de Church-Turing). Esta clase es tan amplia como la de los algoritmos.
5. **No hay contradicción con la diagonalización:** La función universal para funciones recursivas parciales no es calculable, y la función diagonal correspondiente no es recursiva parcial (ni calculable por algoritmo).
